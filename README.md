# nello0b.github.io

Personal portfolio website for Netanel Berkovits, built as a static GitHub Pages site.

## Structure

- `index.html` - page content and semantic structure
- `styles.css` - visual styling and responsive layout
- `assets/images/` - profile and project images used by the site
- `assets/docs/` - downloadable documents, including the public resume
- `references/` - saved examples, shortcuts, and original source files used while building the site
